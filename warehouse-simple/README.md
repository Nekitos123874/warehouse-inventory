# Warehouse Inventory API (Docker Compose + PostgreSQL)

REST API для учёта складских товаров на Java 17, работающее в связке с базой данных PostgreSQL. Вся система запускается одной командой с помощью Docker Compose.

## 🛠 Технологии
* **Java 17** (встроенный HTTP-сервер)
* **PostgreSQL 18.1** (база данных)
* **Docker** и **Docker Compose**

## 🏗 Архитектура проекта
Проект состоит из двух сервисов, описанных в `docker-compose.yml`:
1. **`api`** — Java-приложение (собирается локально из `Dockerfile`).
2. **`db`** — база данных PostgreSQL (используется официальный образ `postgres:18.1`).

**Хранение данных:** Данные базы сохраняются в локальной папке `./pgdata` (примонтирована как volume). Благодаря этому данные **не удаляются** при перезапуске или удалении контейнеров.
