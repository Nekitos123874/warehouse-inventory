\# Warehouse Inventory — Учёт складских товаров



Учебный проект для отработки Git workflow. Реализуется поэтапно:

Git → Linux → Docker → Docker Compose → Архитектура → Финальный проект.



\## Описание

Сервис для учёта товаров на складе: приход, расход, остатки, категории.



\## Функциональность (план)

\- Учёт товаров и их категорий

\- Операции прихода и расхода

\- Отчёты по остаткам

\- Отчёты по движению товаров
