\# Разрешение Git-конфликта



\## Где возник конфликт

При слиянии ветки `feature/stock` в `main` в файле `models.py`.



\## Причина

Ветка `feature/products` и ветка `feature/stock` независимо друг от

друга создали файл `models.py` с определением класса `Product`.

Версия из `products` описывала только базовые поля, версия из `stock`

добавляла поле `quantity`. Git не смог автоматически слить их

(add/add conflict).



\## Как исправлено

Открыл `models.py`, вручную удалил маркеры конфликта

(`<<<<<<<`, `=======`, `>>>>>>>`) и объединил обе версии:

сохранил базовые поля (`id, name, sku, price`) и добавил поле

`quantity=0`.



\## Проверка

\- `git status` показал `both modified: models.py` до разрешения

\- После разрешения: `git add models.py` → `git commit`

\- Все последующие merge прошли без конфликтов
